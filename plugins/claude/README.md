# Dilly Dally Plugin

Find group meeting times and run polls without accounts. Create an event, share the link, collect availability, then pick a date.

This plugin pairs the `dilly-dally` remote MCP server at `https://dally.bradshaw.page/mcp` with a skill that teaches Claude when and how to use it. Install the plugin, connect the `dilly-dally` connector, then ask Claude to create an event, record availability, read back consensus, or run a poll. No sign-in is required because the server needs no authentication. Humans can open the same event in a browser at the shared `/e/:id` URL.
